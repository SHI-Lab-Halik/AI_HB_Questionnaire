# AI Security Capability Questionnaire

An interactive assessment tool for evaluating AI security capabilities across multiple dimensions. This questionnaire helps organizations assess their current AI security posture and identify gaps.

## Overview

The questionnaire covers 11 key security domains:

- **Runtime Security** - AI firewall, threat detection, and data loss prevention
- **Discovery & Inventory** - AI app and model discovery, inventory management
- **Agentic Security** - Security for autonomous AI agents
- **Employee AI Access** - Governing employee use of AI tools
- **Model Scanning** - Supply chain and model integrity verification
- **AI-SPM** - AI Security Posture Management
- **Red Teaming** - Adversarial testing of AI systems
- **AI TPRM** - Third-party AI risk management
- **Compliance** - Regulatory and framework mapping
- **Integrations** - Ecosystem and platform integrations

## Features

- **Interactive Assessment** - Tab-based navigation through security domains
- **Scoring System** - Real-time calculation of completion percentage per domain and overall
- **Flexible Responses** - Rate each capability as Full / Partial / Roadmap / Not supported
- **Vendor Notes** - Add custom notes for vendor-specific details
- **CSV Export** - Export assessment results for sharing and documentation
- **Responsive Design** - Works on desktop and mobile devices
- **Visual Indicators** - Priority badges (Primary/Secondary/Tertiary) for each domain

## Getting Started

1. Open `app.html` in a web browser
2. Navigate through the tabs to explore different security domains
3. For each question, select the appropriate response level
4. Optionally add notes to capture vendor-specific details
5. Watch the score cards update in real-time
6. Export your results as CSV when complete

## Response Options

- **Full** - Capability is fully implemented and in production
- **Partial** - Capability is partially implemented
- **Roadmap** - Capability is planned but not yet implemented
- **Not supported** - Capability is not supported

## Data Structure

The questionnaire includes:
- **11 assessment domains** organized by priority (Primary/Secondary/Tertiary)
- **50+ question groups** covering specific security areas
- **200+ individual questions** assessing detailed capabilities
- **Sub-questions** providing context and clarification for each item

## Export & Reporting

Use the **Export CSV** button to download your assessment results. The CSV includes:
- Section (domain)
- Priority level
- Question group
- Individual questions
- Sub-text/context
- Your responses
- Custom notes

## Priority Levels

- 🟢 **Primary** - Highest priority AI security capabilities
- 🔵 **Secondary** - Important complementary security functions
- ⚫ **Tertiary** - Supporting security and compliance capabilities

## Usage Tips

- Start with Primary priority domains for baseline assessment
- Use notes to record vendor capabilities, timelines, or special considerations
- Export results periodically to track progress
- Share results with security, procurement, and AI governance teams
